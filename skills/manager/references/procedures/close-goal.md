# Close a goal

1. Read the goal's metric from the scoreboard, not from a worker's claim or a report.
2. If the metric meets the target, propose `status: met` with the scoreboard value and date as evidence.
3. If the deadline has passed and the metric misses, propose `status: missed` with the value, and say in the report whether to replace it.
4. If the goal no longer serves the charter, propose `status: closed` with the reason.
5. Every status change is a proposal: it lands as a pull request the human merges.
